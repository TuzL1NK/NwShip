NwShip — 最终幻想14潜艇探索助手
=====================

简介
----
NwShip 是一个基于 Qt 的桌面应用，用于计算并展示潜艇探索航线的建议。程序使用 CMake 构建，支持 Debug/Release 模式。

要求
----
- Qt 6（或 Qt 5）Widgets
- CMake 3.16+
- MinGW-w64（Windows）或等价的编译工具链


程序运行
----
右侧[Releases 页面](https://github.com/TuzL1NK/NwShip/releases)开袋即食
